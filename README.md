📊 Online Sales Interactive Dashboard (Power BI)

An end-to-end business intelligence dashboard built in Power BI to track, analyze, and visualize online sales performance, customer trends, and key business metrics.

🚀 Project Overview

This project focuses on transforming raw transactional data into actionable insights. By establishing robust data models, relationships, and advanced filtering techniques, the dashboard empowers stakeholders to perform deep-dive data analysis dynamically.

💡 Key Learnings & Technical Highlights

Interactive Dashboard Design: Created an intuitive dashboard to track and analyze online sales data effectively.

Advanced Parameters & Filtering: Used complex parameters to enable drill-down capabilities, customized filtering, and slicers.

Data Modeling & Calculations: Created connections, joined new tables, and used calculations to manipulate data and enable user-driven parameters for visualizations.

Diverse Visualizations: Utilized various types of customized visualizations, including:

Bar charts & Clustered bar charts

Pie charts & Donut charts

Line charts & Area charts

Scatter charts

Maps & Slicers

🛠️ Tools & Technologies Used

Power BI Desktop: Dashboard creation, data modeling, calculations, and visual design.

Power Query: Data cleaning, transformation, and joining tables (Orders.csv, Details.csv).

Git & GitHub: Version control and repository hosting.
